# Как работать в разделе команды

Короткие инструкции для задач команды KOL Arena. Все разделы открываются из `/team` после входа.

## Добавить или убрать сотрудника

Только администратор.

1. Откройте «Staff».
2. Добавить: «Add staff», затем логин, роль и пароль. Логин: латиница, цифры, точка, дефис, подчёркивание. Пароль: не меньше 10 символов.
3. Убрать: «Revoke» у сотрудника, затем «Revoke access». Он выйдет сразу и больше не войдёт.

Свой доступ убрать нельзя.

## Подтвердить кошелёк, который нашла система

1. Откройте «Wallets».
2. Найдите KOL со статусом «Hypothesis».
3. Спросите KOL, его ли это кошелёк.
4. Да: «Confirm» и где и когда он подтвердил. Нет: «Reject», причину можно указать.

Гипотеза никогда не видна клиенту. На борд идут только подтверждённые кошельки.

Гипотезы появляются сами после каждого чтения таблицы сети. Запустить поиск вне расписания: «Run the wallet pass».

## Добавить адрес, который прислал KOL

1. Откройте «Wallets».
2. Нажмите «Add an address from the KOL».
3. Выберите KOL, вставьте адрес Solana и укажите, откуда он.

Сайт проверит сделки по адресу. Есть сделки: адрес подтверждён. Нет сделок: адрес сохранён как «Not found».

## Сменить основной кошелёк KOL

1. Откройте «Wallets» и найдите KOL.
2. У нужного подтверждённого адреса нажмите «Make main».

Цифры борда считаются по основному кошельку.

## Снять кошелёк с борда

1. Откройте «Wallets» и найдите KOL.
2. У подтверждённого адреса нажмите «Revoke» и укажите причину. Причина обязательна.

Кошелёк сразу уходит с борда.

## Разобрать конфликт адреса

Статус «Conflict»: адрес указан у двух KOL. Ни у кого он не публикуется.

1. Спросите обоих KOL, чей это адрес.
2. У KOL, которому адрес не принадлежит, нажмите «Reject».

## Записать проверенный хэндл X и охват

1. Откройте «Network».
2. Нажмите «Edit» у KOL.
3. Задайте хэндл X, форматы и охват. Пустыми оставьте поля, которые не проверили.

Сохранённый хэндл считается проверенным. Проверьте профиль X заранее. После сохранения сайт сам ищет кошелёк по этому хэндлу.

## Найти кошелёк по профилю FOMO

1. Откройте профиль KOL на FOMO в браузере.
2. Откройте «FOMO match» в разделе команды.
3. Перепишите 2 или 3 позиции: адрес токена и сумму, как их показывает FOMO.
4. Запустите сверку. Она читает держателей токена, до минуты на позицию.

Подходит кошелёк, который держит хотя бы 2 позиции. Сумма должна совпасть с точностью 0,5%.

- Один такой кошелёк: он станет гипотезой в «Wallets». Подтвердите его у KOL.
- Несколько: итог «Several wallets», ничего не сохраняется. Добавьте третью позицию.
- «Busy»: идёт сбор или чтение таблицы. Ничего не сохранено, повторите позже.

## Прочитать таблицу сети вне расписания

Только администратор.

1. Откройте «Network».
2. Нажмите «Read the sheet now».

Строки с ошибкой сайт пропускает и перечисляет под итогом. Остальные строки читаются.

## Запустить сбор вручную

Только администратор.

1. Откройте «Collection».
2. Оставьте дату пустой для сегодняшнего дня или выберите прошлую.
3. Нажмите «Run now».

Источники отдают только сегодняшние цифры. Поэтому прошлая дата не собирается заново: её снимок только закрывается и ранжируется ещё раз. Дату без снимка и будущую дату сайт не примет.

## Подобрать KOL сети под клиента

1. Откройте «Picker».
2. Задайте фильтры: Score, тир, ставка, формат.
3. Отметьте нужных KOL.
4. «Export for client» скачает список без ставок. «Export with rates» скачает со ставками для команды.

Файл со ставками клиенту не отправляйте.

## Выключить блок сайта

Каждый блок можно выключить без пересборки. Задайте в настройках сайта `ARENA_IMPL_RULES` и перезапустите сервер:

```
ARENA_IMPL_RULES='[{"plugin":"guess","use":"off"}]'
```

Правило можно ограничить ролью (`"role":"nobody"` для клиентов) или сотрудником (`"person":12`). Остальные блоки работают как прежде.

## Запустить сайт задачи или staging

Из корня репозитория:

```
PORT=<порт> scripts/site.sh task      # сайт задачи, база kol_fight_wt_<папка>
PORT=<порт> scripts/site.sh staging   # общий staging, база kol_fight_staging
scripts/site.sh teardown              # удалить базу задачи
```

Настройки сайт читает из `tmp/site.env` (задача) или `~/.config/kol-fight/staging.env` (staging). Список настроек — в «Справочник KOL Arena» (`reference-kol-arena.md`).
