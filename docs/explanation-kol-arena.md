# Как устроена KOL Arena и почему так

Объяснение главных решений. Шаги работы — в `how-to-team.md`, точные значения — в `reference-kol-arena.md`.

## Слои и блоки

Сайт собран из 21 блока в пяти слоях:

- Слой 0, общее: вход сотрудников, журнал изменений.
- Слой 1, арена: клиентская страница, рейтинг, бой. Работает на сохранённом снимке, без сбора.
- Слой 2, ежедневные данные: сбор из KOL Explorer и Solana Tracker, расписание, радар.
- Слой 3, наша сеть: таблица сети, кошельки, сверка FOMO, подбор под клиента.
- Слой 4, игры: дуэль, «угадай», ходы, серии, турнир.

Верхний слой добавляет к нижнему, нижний о нём не знает. Поэтому любой блок можно выключить правилом `ARENA_IMPL_RULES`. Остальные работают дальше, а на месте выключенного блока ничего не ломается.

Так продукт растёт по частям. Арена живёт без сети, сеть без игр.

## Почему два источника

KOL Explorer даёт только сегодняшний топ-100 по прибыли. KOL нашей сети часто вне этого топа. Solana Tracker закрывает их по публичному кошельку.

Цена: у KOL из Solana Tracker нет прибыли за 24 часа. Остальные цифры есть у обоих.

Оба источника отдают только текущие цифры. Поэтому прошлую дату нельзя собрать заново: её снимок можно только закрыть и ранжировать ещё раз.

## Почему гипотеза кошелька закрыта

Система может ошибиться в адресе. Чужой кошелёк на публичной странице приписал бы KOL чужие сделки. Это бьёт по KOL и по доверию клиента.

Поэтому догадка остаётся гипотезой до слова самого KOL. Догадка — это адрес по непроверенному хэндлу X или по сверке FOMO. Клиент видит только подтверждённые кошельки. Подтверждение команда записывает: где и когда KOL его дал.

Адрес подтверждается сам, только когда за ним стоит источник, которому мы верим: таблица сети, сам KOL или проверенный хэндл.

Адрес, указанный у двух KOL, не публикуется ни у кого, пока команда не решит.

## Почему ставки не уходят с сервера

Ставки, условия и заметки — коммерческая тайна. Они живут только в таблицах сети. Ни один публичный адрес сервера их не отдаёт, в собранный сайт они не попадают, в журнал не пишутся.

Адрес таблицы тоже секрет: по нему видны ставки. Он хранится только в настройках сервера.

Выгрузка подбора для клиента идёт без ставок. Выгрузка со ставками — для команды.

## Почему сайт не читает FOMO, GMGN, Kolscan, Solscan

Их правила запрещают автоматическое чтение. Сайт даёт только ссылки. Сверку FOMO сотрудник начинает сам: переписывает позиции, а сайт ищет держателей через публичный RPC Solana.

## Как устроен Score

Score отвечает клиенту на один вопрос: стоит ли следить за этим KOL. Поэтому главный вес у прибыли за 30 дней. Точность считается, только когда KOL в плюсе: высокая доля удачных сделок при убытке ничего не значит.

Прибыль идёт по логарифму. Разница между $1,000 и $10,000 весит столько же, сколько между $50,000 и $500,000. Иначе пара китов заняла бы весь верх.

Часть без данных даёт 0, а не среднее. Рейтинг не выдумывает цифры, которых нет.
