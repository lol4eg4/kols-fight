# Справочник KOL Arena

Настройки, страницы, адреса сервера, роли, статусы и формулы.

## Настройки сервера

Сервер читает их из окружения при старте. `scripts/site.sh` задаёт `DATABASE_URL`, `WEB_DIST` и `COMMIT` сам; `PORT` передаётся ему.

- `PORT`: порт сервера. Обязателен.
- `DATABASE_URL`: база Postgres. Обязателен.
- `WEB_DIST`: папка собранного сайта (`web/dist`). Обязателен.
- `COMMIT`: коммит сборки, его показывает `/api/health`.
- `SOLANA_TRACKER_API_KEY`: ключ Solana Tracker. Без него этот источник не собирается.
- `NETWORK_SHEET_CSV_URL`: адрес выгрузки CSV листа `Influencers` таблицы сети. Секрет: в адресе видны ставки.
- `FIRST_ADMIN_LOGIN`, `FIRST_ADMIN_PASSWORD`: первый администратор. Создаётся при запуске, если администратора нет.
- `PUBLIC_RPC_URL`: публичный RPC Solana для сверки FOMO.
- `ARENA_IMPL_RULES`: список правил JSON, какие блоки выключены. Без него все блоки включены.

Пустая настройка показывается в нужном блоке как «not configured». Остальные блоки работают.

Правило `ARENA_IMPL_RULES` имеет поля:

- `plugin`: имя блока. Обязательно.
- `use`: имя реализации или `off`. Обязательно.
- `app`, `role`, `person`: для кого правило. Пусто: для всех.

Побеждает самое точное правило: сначала `person`, потом `role`, потом `app`. Среди равных побеждает последнее.

## Расписание

- 05:45 UTC: чтение таблицы сети.
- 06:00 UTC: ежедневный сбор и пересчёт рейтинга.

## Страницы

Для клиента, без входа:

- `/`: топ-3, лидерборд, игры.
- `/kol/:id`: карточка KOL.
- `/fight`: бой от 2 до 4 KOL.

Для команды, после входа:

- `/team/login`: вход.
- `/team/wallets`: кошельки.
- `/team/network`: таблица сети.
- `/team/collection`: сбор данных.
- `/team/fomo`: сверка FOMO.
- `/team/picker`: подбор KOL под клиента.
- `/team/design`: образцы оформления.
- `/team/staff`: сотрудники. Только администратор.

## Роли

- Клиент: без входа. Видит только клиентские страницы и публичные ответы сервера.
- Staff: все разделы команды, кроме «Staff». Не запускает сбор и чтение таблицы вручную.
- Admin: всё.

После 5 неверных паролей вход с этого адреса закрыт на 15 минут.

## Адреса сервера

Публичные:

- `GET /api/health`
- `GET /api/board`
- `GET /api/kol/{id}`
- `GET /api/fight`, `GET /api/fight/image`
- `GET /api/duel`
- `GET /api/moves`
- `GET /api/network`
- `GET /api/radar`
- `GET /api/streaks`
- `GET /api/tournament`, `GET /api/tournament/lineups`

Вход:

- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

Команда:

- `/api/team/wallets`, с действиями `/{id}/confirm`, `/{id}/main`, `/{id}/reject`, `/{id}/revoke`, а также `/pass` и `/propose`.
- `/api/team/network`, `/api/team/network/{kol}`, `/api/team/network/export`.
- `/api/team/picker`, `/api/team/picker/export`. Параметр `rates=1` добавляет ставки.
- `/api/team/fomo/match`.

Администратор:

- `/api/admin/staff`, `/api/admin/staff/{id}/revoke`.
- `POST /api/admin/collection/run`.
- `/api/admin/network/sync`.

`GET /api/admin/collection` открыт и для Staff.

Действия команды принимаются только с самого сайта.

## Статусы кошелька

- Hypothesis: система нашла адрес по непроверенному хэндлу X или по сверке FOMO. Клиенту не виден.
- Confirmed: адрес подтверждён. Сразу публичный, если его не указал другой KOL.
- Not found: по адресу нет сделок.
- Rejected: KOL сказал, что адрес не его.
- Revoked: команда сняла адрес с борда.
- Replaced in the sheet: таблица сети теперь даёт другой адрес.
- Conflict: адрес указан и у другого KOL. Ничего не публикуется, пока команда не решит.

Адрес подтверждается сам в трёх случаях:

- адрес из таблицы сети, и по нему есть сделки;
- адрес прислал KOL, и по нему есть сделки;
- метка кошелька совпала с проверенным хэндлом X.

Остальные подтверждает сотрудник кнопкой «Confirm». На борд идёт только основной подтверждённый кошелёк.

## Arena Score

Score от 0 до 100:

- Profit, 40%: прибыль за 30 дней, логарифм от $1,000 до $500,000.
- Accuracy, 25%: доля удачных сделок за 30 дней, от 30% до 80%. Если её нет, берётся доля за всё время. Считается только при прибыли за 30 дней больше нуля.
- Form, 20%: прибыль за 7 дней, логарифм от $500 до $100,000.
- Activity, 15%: последняя сделка. До 60 минут: полный балл, 30 дней и дольше: ноль.

Часть без данных даёт 0.

Тиры:

- GOAT: 70 и выше.
- Diamond: 50–69.
- Sendoor: 35–49.
- Degen: ниже 35.

## Источники

- KOL Explorer: сегодняшний топ-100 по прибыли, с прибылью за 24 часа.
- Solana Tracker: KOL с публичным кошельком вне этого топа. Прибыли за 24 часа не даёт.
- Таблица сети: ставки, форматы, заметки. Только для команды.
- FOMO, GMGN, Kolscan, Solscan: только ссылки. Сайт их не читает.
